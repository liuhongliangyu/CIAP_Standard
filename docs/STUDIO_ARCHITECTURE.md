# Studio Architecture


Studio 是配置系统，不是运行系统。


## Designers


World Designer:

创建：

- Factory
- Zone
- Machine
- Rack
- Navigation


Entity Designer:

配置：

- Template
- Capability
- Parameter


Process Designer:

定义：

- Operation
- Sequence
- Requirement


Policy Designer:

绑定：

- Routing
- Dispatch
- Scheduling


Scenario Designer:

定义：

- Orders
- Fleet
- Parameters


## 输出

Studio 输出：

Product Recipe

World Definition

Process Definition

Scenario Definition

Policy Binding


Runtime 消费这些定义。
